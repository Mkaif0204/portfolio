# Mohd Kaif — Personal Portfolio

Minimalist, classy portfolio website of **Mohd Kaif** (B.Tech CSE in Artificial Intelligence & Machine Learning at Guru Nanak Institution Technical Campus, Hyderabad • CGPA 8.5).

Built with semantic HTML5, modern CSS3, and vanilla JavaScript. Features a warm off-white/beige aesthetic, clean typography, grounded technical skills, and featured projects.

---

## 🚀 Live Demo & Local Preview

### Option 1: Open Directly
Simply double-click `index.html` to open it in any web browser.

### Option 2: Run Local Server
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## 📤 Push to GitHub

If you created a new repository on your GitHub (e.g. `portfolio` or `Mkaif0204.github.io`):
```bash
git remote add origin https://github.com/Mkaif0204/<YOUR_REPO_NAME>.git
git push -u origin main
```

### Enable GitHub Pages (Free Hosting)
1. Go to repository **Settings** → **Pages**.
2. Source: **Deploy from a branch** → Branch: `main` / `root`.
3. Click **Save**. Your site will be live in 1 minute!
